# 장기기억 (Project Memory)

> 새 세션이 이전 맥락을 바로 이어받도록, 프로젝트 개발에 필요한 핵심만 요약해 둡니다.
> 루트 `CLAUDE.md`가 이 폴더의 문서를 세션마다 자동으로 불러옵니다.
>
> [위키 홈](../README.md)

## 구성

| 문서 | 담는 내용 |
|---|---|
| [project](project.md) | 프로젝트 개념: 목적, 성격, 도메인 핵심, 서비스 후보, 저장소 |
| [design](design.md) | 설계 요약: 확정된 결정, 검토 중인 항목, 설계 원칙 |
| [policies](policies.md) | 정책 / 규칙: 개발 흐름, 문서, 기록, Git, 작업 환경 |
| [sessions](sessions.md) | 세션 이력: 세션별 한 줄 요약, 현재 상태, 다음 할 일 |

## 작성 원칙

- **요약과 링크만 둡니다.** 상세 내용의 원본은 위키 본문(ADR, 설계 문서, worklog)이고, 여기에는 핵심과 원본 링크만 적습니다.
- **짧게 유지합니다.** 세션마다 전부 로드되므로 문서당 한 화면 안팎을 목표로 합니다. 오래되어 쓸모없는 내용은 지웁니다.
- **확정과 검토 중을 구분합니다.** 검토 중인 항목을 확정처럼 적지 않습니다.
- **사실만 적습니다.** 추측이나 개인 선호는 적지 않습니다.

## 갱신 시점

- `/worklog` 스킬을 실행할 때 함께 갱신합니다.
  - [sessions](sessions.md): 세션 행 추가, 현재 상태와 다음 할 일 교체
  - 이번 세션에서 개념, 설계, 정책이 바뀌었다면 해당 문서도 갱신
- ADR이 추가되거나 대체되면 [design](design.md)을 갱신합니다.
