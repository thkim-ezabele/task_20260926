## 작성 방법

1. [0000-template.md](0000-template.md)를 복사합니다.

4. 결정이 바뀌면 기존 ADR은 수정하지 않습니다. 새 ADR을 작성한 뒤 기존 ADR의 상태를 `대체됨`으로 변경합니다.
