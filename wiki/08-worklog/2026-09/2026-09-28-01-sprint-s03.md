## 이슈 / 배운 점

- Skill 도구 호출이 `disable-model-invocation`으로 막혔다. 오케스트레이션 세션이 사용자 승인을 근거로 스킬 파일을 바꿨고(92b7e16), 이 세션은 그 승인을 직접 확인하지 못해 사용자에게 알렸다.
- Edge `--screenshot`은 Blazor 대시보드가 빈 화면으로 찍혀, CDP(`--remote-debugging-port`)로 캡처했다.
- 판정 기준이 작업 중에 늘었다: 재시작 42P04 한 쌍, 첫 실행 3D000(Aspire 헬스 검사 잡음), 비밀 점검 가짜 값 제외. 계획 리뷰에 '알려진 잡음' 절이 필요하다.
- 로컬 Docker API 1.43이라 Testcontainers 4.15.0에 `DOCKER_API_VERSION=1.43`이 필요했다(CI 무관, BL-102). 개발 인증서 미신뢰면 https 프로필 대시보드에 로그 · 추적이 0건이다(BL-099).
- 실제 AppHost 실행 증빙이 단위 · TestServer로 안 보이던 요청 완료 로그 누락을 찾았다.
- 표 편집 스크립트가 빈 셀을 잘못 나눠 표 결함 21건을 만들었다가, 파일을 되돌리고 셀 파싱으로 다시 적용했다.
- Respawn 이력 테이블 제외는 이름 대소문자를 그대로 비교하고, "1회만 실패" 카운터는 롤백되지 않는 시퀀스로 세야 한다(실측).
