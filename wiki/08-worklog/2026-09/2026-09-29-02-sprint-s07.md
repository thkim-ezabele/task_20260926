## 이슈 / 배운 점

- .NET 8 ExceptionHandlerMiddleware는 처리기 호출 전에 endpoint를 지운다. 500 경로에서 템플릿은 `IExceptionHandlerFeature.Endpoint`로 읽어야 한다.
- 이름 부재 단언은 NFC · NFD × 퍼센트 인코딩 대 · 소문자까지 봐야 한다(서수 Contains가 한 형태만 잡음, T02 tester 보강).
- Git Bash 내장 curl 8.6.0(mingw)은 명령줄 한글을 CP949로 보내 21022가 난다. Windows `System32\curl.exe` 8.21.0은 UTF-8(BL-142).
- 도구 인자에서 역슬래시가 빠지는 문제가 문서 반려 1회를 만들었다(local-setup 경로). node `String.fromCharCode(92)` + `od -c` 확인으로 고쳤다.
- DoD CI 기록 커밋에서 진행 기록 행을 실행 기록 표 뒤에 붙여 check-docs table 결함 2건을 만들었고, 바로 다음 커밋(59bee8c)에서 고쳤다.
- CI 측정값은 로그에 없고 test-results 산출물 trx에만 있다(`gh run download`).
