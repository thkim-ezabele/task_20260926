| Infrastructure 예외(RetryLimitExceeded → 9003)는 Application 분류 포트 + Infrastructure 구현 | Api가 EF 형식을 모르게 유지 | ADR-0024 |
| xmin은 EF shadow property(Domain 무변경) | Domain 영속성 비의존(ADR-0003) | - |
| 매핑 없는 23505 = 3003 `Common.UniqueConstraintViolated` | 3003이 비어 있고 네 에이전트 동의 | - |
| IIdGenerator는 ADR-0017 해석대로 명시 Scoped 등록 | ADR-0013 "자동 등록" 문구는 수명 근거로 해석 | - (BL-066에 기록) |
| Validator 공통 기반 RequestValidator, MustBeDefinedEnum([Flags] 조합 허용) | ADR-0018이 설정 위치를 S02-T02에 맡김, 계획 리뷰 결정 | ADR 후보 (ADR-0018 보충) |

- 스프린트 소요 약 4시간 30분, developer 단계가 약 70%(작업당 7~31분). 사용자가 셋팅 단계치고 오래 걸린다고 문제를 제기 → 운영 변경과 테스트 범위 결정으로 대응.
- 반려 3회 중 2회가 테스트 코드 컨벤션(한 파일 한 형식, enum 기반 형식). 기계로 막을 수 있는 규칙이라 developer 자체 점검 항목에 추가함.
- developer가 완료 조건 항목을 혼자 백로그(BL-078)로 내보냈다가 반려됨 → 임의 이관 금지(BLOCKED로 판단받음) 규칙 추가.

- Git Bash에서 `node -e`에 한글 리터럴을 넘기면 치환이 되지 않았다(인코딩). 스크래치 스크립트 파일로 우회.
