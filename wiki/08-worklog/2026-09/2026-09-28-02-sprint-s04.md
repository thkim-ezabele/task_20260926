## 이슈 / 배운 점

- 반려 6회가 모두 문서 · 증빙 작업에서 나왔다. 사실 문장을 실측 없이 옮기거나, 완료 조건을 증빙 틀로 옮기며 칸을 빠뜨린 것이 원인이다.
- 원격 토픽 브랜치가 뒤처져 GitHub clone 재현 대신 로컬 clone으로 재현했다.
- clone과 원래 트리가 같은 UserSecretsId · 볼륨 이름을 공유해 재현 초기화가 원래 트리 상태도 새로 만들었다(원래 트리는 새 비밀번호 쌍 · 새 볼륨을 쓴다).
- Edge `--dump-dom`은 Blazor 렌더링 전에 끝나 CDP로 덤프해야 했다(BL-118).
- 보조 스크립트의 표 행 찾기가 같은 머리글로 시작하는 다른 표 행을 먼저 잡아 두 번 고쳤다. 쓰기 전에 실패해 파일 손상은 없었다.
- 개발 인증서가 신뢰되지 않아 기본 https 프로필 수신은 사용자 확인 사항으로 남겼다.
